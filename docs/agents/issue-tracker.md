# Issue tracker: GitHub

Issues and specs live in FireSquid6/ruf-bulletin-generator on GitHub.
Use `gh` from this repository to create, read, comment on, label, and close issues.

## Dependencies

Use GitHub’s native blocked-by relationships where available.
Otherwise, put `Blocked by: #<number>` in the issue body.
A ticket is ready only when all its blockers are closed.

## Publishing

Create tickets in dependency order and apply `ready-for-agent`.
If breaking down an existing issue, link tickets as its sub-issues.
Do not close or modify the parent issue.

## Pull requests as a triage surface

PRs as a request surface: no.
